How to Install or Update on Android (No USB Required)

  1. Tap Download Latest APK above to save ISCEB-latest.apk directly to your phone (prefer Chrome / browser download over WhatsApp forwarding).
  2. Open the downloaded file from your browser Downloads or notification bar.
  3. If Android prompts for security permission, enable Allow from this source for Chrome / Files / ISCEB app.
  4. Tap Update (or Install). Your login state, course progress, uploaded materials, and certificates remain safely preserved.
If Android shows “App not installed”:
  • If an older build from a different source/key is already installed on the phone: open Profile → Export Backup inside the old app first to save your .json data, then uninstall the old build, install this APK, and tap Restore Backup.
  • Always open the APK from Chrome Downloads / Files rather than directly inside WhatsApp if WhatsApp blocks package installation.
